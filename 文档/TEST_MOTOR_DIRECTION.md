## 理论说明

**共轴反桨原理**:
- 同一轴上的两个螺旋桨必须反向旋转
- 目的：抵消反扭矩，避免机体自旋
- 推力方向相同（都向下），扭矩方向相反

**当前布局**:
```
     CCW      CCW       ← 上层都是CCW
      |        |
   [右臂]   [左臂]
      |        |
     CW        CW        ← 下层都是CW
```

这样每条臂的上下反向，整体扭矩平衡。

如果观察到异常，请详细描述你看到的现象！
