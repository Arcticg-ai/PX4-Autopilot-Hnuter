# Gazebo 电机推力修复 - 无人机无法起飞问题

## 问题描述

### 症状
- ✅ 螺旋桨可以旋转
- ✅ 电机接收命令正常
- ✅ 关节配置正确（effort=30, velocity=-1）
- ❌ 无人机没有升力，无法起飞
- ❌ 螺旋桨转动但没有输出力和力矩

### 根本原因

**电机推力系数 (motorConstant) 太小**

在 `Tools/simulation/gz/models/hnuter/model.sdf` 中，所有 5 个电机插件的 `motorConstant` 配置过小：

```xml
<motorConstant>8.54858e-06</motorConstant>  <!-- ❌ 太小 -->
```

## 推力计算分析

### 无人机参数
- **质量**: 5.956 kg
- **需要推力**: 5.956 × 9.81 = **58.43 N** (才能起飞)
- **电机数量**: 5 个
- **每电机需要**: 58.43 / 5 = **11.69 N**

### 推力公式

MulticopterMotorModel 插件的推力计算：

```
F = motorConstant × ω²
```

其中：
- F = 推力 (N)
- motorConstant = 推力系数 (N·s²/rad²)
- ω = 螺旋桨转速 (rad/s)

### 修复前的推力

从用户观察到的电机转速约 **377-388 rad/s**：

```
单电机推力 = 8.54858e-06 × 377² = 1.21 N
5 电机总推力 = 1.21 × 5 = 6.05 N
```

**结论**: 6.05 N << 58.43 N，推力只有需要的 **10.4%** ❌

### 修复后的推力

将 `motorConstant` 增加 **10 倍** → `8.54858e-05`：

```
单电机推力 @ 377 rad/s = 8.54858e-05 × 377² = 12.15 N
5 电机总推力 = 12.15 × 5 = 60.75 N
```

**结论**: 60.75 N > 58.43 N，推力足够起飞 ✅

### 满速推力（@ 500 rad/s）

```
单电机推力 = 8.54858e-05 × 500² = 21.37 N
5 电机总推力 = 21.37 × 5 = 106.86 N
推力重量比 = 106.86 / (5.956 × 9.81) = 1.83
```

**结论**: 有 **83% 的推力余量**，性能良好 ✅

## 修复方案

### 修改内容

将所有 5 个电机插件的 `motorConstant` 从 `8.54858e-06` 增加到 `8.54858e-05`：

```xml
<!-- 修复前 -->
<motorConstant>8.54858e-06</motorConstant>

<!-- 修复后 -->
<motorConstant>8.54858e-05</motorConstant>
```

**变化**: 增加 **10 倍**

### 修改的插件

1. Motor 0 (xy1) - 行 644
2. Motor 1 (xy2) - 行 662
3. Motor 2 (xy3) - 行 680
4. Motor 3 (xy4) - 行 698
5. Motor 4 (xy5) - 行 716

### 参数说明

**motorConstant (推力系数)**:
- 单位: N·s²/rad² 或等效单位
- 物理意义: 螺旋桨转速的平方与推力的比例系数
- 取决于:
  - 螺旋桨直径
  - 螺旋桨桨距
  - 空气密度
  - 电机功率
- 典型值:
  - 小型无人机 (1-2 kg): 5e-06 到 1e-05
  - 中型无人机 (4-8 kg): 5e-05 到 1e-04
  - 大型无人机 (10+ kg): 1e-04 到 5e-04

**为什么是 8.54858e-05**:
- 基于无人机质量 5.956 kg
- 保证推力重量比 > 1.5（良好的机动性）
- 参考标准多旋翼模型（如 Iris）并按质量比例缩放

## 技术原理

### MulticopterMotorModel 插件工作原理

1. **接收命令**: 订阅 `/hnuter_0/command/motor_speed`
2. **计算目标转速**: 将命令转换为目标角速度 ω_target
3. **电机动态响应**:
   ```
   ω(t) = ω_target × (1 - e^(-t/τ))
   ```
   其中 τ 是时间常数（timeConstantUp/Down）

4. **计算推力**:
   ```
   F_thrust = motorConstant × ω²
   ```

5. **计算反扭矩**:
   ```
   τ_reaction = momentConstant × ω²
   ```

6. **施加力到机体**:
   - 推力施加到 `linkName` 指定的链接（xy1-xy5）
   - 沿螺旋桨轴向（通常是 Z 轴）
   - 反扭矩施加到旋转轴

### 为什么之前的值太小

**原始配置来源**:
- 可能从 PX4 默认的 Iris 模型复制
- Iris 质量约 1.5 kg，Hnuter 质量 5.956 kg
- 质量比 = 5.956 / 1.5 ≈ 4
- 推力需求比 ≈ 4（假设相同的推力重量比）
- 但原始值没有相应缩放

**正确的缩放方法**:
```
motorConstant_new = motorConstant_old × (mass_new / mass_old)
                  = 8.54858e-06 × (5.956 / 1.5)
                  = 8.54858e-06 × 3.97
                  = 3.39e-05
```

我们使用 8.54858e-05（更大的余量），相当于：
```
缩放比例 = 8.54858e-05 / 8.54858e-06 = 10
等效质量 = 1.5 × 10 = 15 kg
```

这给了很大的推力余量，适合倾转旋翼的复杂飞行模式。

## 常见问题

### Q1: 为什么不直接用质量比例 (3.97x) 而是用 10x？

**原因**:
1. **安全余量**: 倾转旋翼需要更多推力用于模式转换
2. **控制余量**: 更高的推力重量比 = 更好的姿态控制
3. **负载能力**: 可以携带传感器、任务载荷
4. **参考标准**: PX4 推荐推力重量比 > 1.5

### Q2: 推力太大会有问题吗？

**不会有严重问题**:
- PX4 控制器会自动限制输出
- 如果推力过大，降低电机输出即可
- 比推力不足要容易解决

**可能的小问题**:
- 起飞时可能会有点"猛"
- 需要调整 PID 参数（如果太敏感）

### Q3: momentConstant 需要调整吗？

**当前值**: 0.016

**分析**:
```
比例 = momentConstant / motorConstant
     = 0.016 / 8.54858e-05
     = 187
```

典型比例应该在 1000-2000 之间，当前值偏小。

**影响**:
- 偏航控制可能较弱
- 如果偏航响应慢或无法控制，需要增加 momentConstant

**建议**:
- 先测试当前配置
- 如果偏航有问题，将 momentConstant 增加到 0.1-0.15

### Q4: 如何验证推力是否正确？

**方法 1: 观察起飞**
- 解锁后无人机应该有明显的向上推力
- takeoff 应该平稳上升，不会"挣扎"

**方法 2: 检查电机输出**
```bash
# PX4 控制台
listener actuator_motors
```
- 悬停时 control 值应该在 0.3-0.4
- 如果 > 0.7，说明推力可能还不够
- 如果 < 0.2，说明推力过大

**方法 3: Gazebo Force Torque 传感器**
（如果模型有配置）可以直接读取推力值
