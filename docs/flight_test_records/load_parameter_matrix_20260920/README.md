## 切换负载时的实际操作顺序

1. 确认固件身份（`ver all`）、电池型号、最终总质量、一级倾转轴到真实重心的**有符号** X/Z 偏移及尾电机到重心力臂。不要因更换电池只改 `HNTR_MASS` 而沿用不匹配的 CG。
2. 保存当前整机参数备份，再依次核对 `HNTR_MASS`、`HNTR_CG_X/Z`、`HNTR_MOT_HOV` 和电池监测参数。`MOT_HOV` 是前馈起点，需根据稳定悬停输出校正；不要用 Z 增益掩盖质量误差。
3. 在拆桨/系留条件下核对尾电机方向和中点；再做低高度、低水平加速度悬停。Pitch `KR/D/I/Bias/TAU_P` 一次只改一类，按新 ULog 评估，不能一次套用未验证的整组候选。
4. 位置源是独立配置：动捕记录通常 `EKF2_EV_CTRL=11, EKF2_GPS_CTRL=0`；RTK log189 为 `0/11`。切换定位源时单独核对，不要把它误当成电池参数。

`BAT1_CAPACITY` 在这些日志起始快照中均为 `-1`。旧[三电池建议表](../battery_comparison_20260828/recommended_parameters.csv)中的 `10000/7200/5600 mAh` 是当时按任务可用量提出的候选，**并非这些 ULog 实际使用的设置**；特别是半固态电池未完成明确满充至截止的验证，不能据此确认物理可用容量。电池告警/容量估计须独立校准，不宜直接将候选表写进飞控。

## 与工作区的关系

整理资料时的已发布实机代码基线为 `acff025a`；本次把 `HNTR_CG_X` 在机型文件和参数定义中改为 `0.055 m`。这只影响**将来按包含此修改的源码重新编译且未被已保存参数覆盖**的默认值；既不改写旧 ULog，也不证明当前飞控已采用该值。切换负载仍以飞控 `param show` 和新 ULog 的参数快照为准。本矩阵不修改控制律，也不为任何负载组合颁发新的 OK 标记。
