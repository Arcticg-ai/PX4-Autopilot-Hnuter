# Hnuter 舵机辨识版本分支说明

日期：2026-07-21

## 分支划分

固件仓库：

- `codex/hnuter-pre-servo-id-20260721`：加入舵机辨识参数前的完整 Hnuter 控制固件。
- `codex/hnuter-servo-id-20260721`：加入舵机辨识响应后的版本，也是后续修改分支。

外部控制器仓库：

- `codex/hnuter-controller-pre-servo-id-20260721`：不使用辨识动态的完整外部控制器。
- `codex/hnuter-controller-servo-id-20260721`：与辨识后仿真模型配套的外部控制器。

## 辨识后版本的建模边界

辨识得到的纯延迟、一阶惯性和速度限制属于舵机与传动机构的物理响应，只在
`Tools/simulation/gz/models/hnuter/model.sdf` 的 `HnuterServoDynamics` 仿真模型中实现。

PX4 控制分配和外部直接控制器不再重复预测或限制这段动态。它们只保留一级、
二级倾转的静态传动比补偿，用于将期望关节角换算为执行器归一化指令。Gazebo
关节自身的速度上限保持为宽松保护值，实际动态由舵机插件统一产生。

仿真参数采用左右对称、正反向一致的近似值，目标是复现实机主要响应量级，而
不是逐通道精确复制辨识噪声和机械差异：

| 机构 | 静态增益 | 时间常数 | 纯延迟 | 速度上限 |
| --- | ---: | ---: | ---: | ---: |
| 一级倾转 | 1.414 | 0.071 s | 0.108 s | 5.5 rad/s |
| 二级倾转 | 0.700 | 0.151 s | 0.147 s | 3.0 rad/s |

SITL 默认设置 `HNTR_TDYN_EN=0`，防止控制分配器再次叠加延迟、一阶惯性和速度
限制。该参数保留用于专门的估计器对比实验，不应与 Gazebo 舵机动态同时启用。

## 验证方式

```bash
ROS_DOMAIN_ID=42 ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST make px4_sitl gz_hnuter
```

外部控制器也使用相同的 `ROS_DOMAIN_ID` 和仅本机发现范围。测试时确认一级、二级
倾转存在合理的响应延迟，但不会因控制器和模型重复限速而额外变慢。
