- 数据源：`tail_motor_bench_raw_2026-08-11.xls`

## 2. 稳态拟合

实测中位点是 1500 us。1500 us 的稳态转速为 0 RPM；1450 us 仍约为 -4419 RPM，因此不能把 1450 us 当成该电调/电机组合的停止点。

以 1500 us 为固定中位点，分方向拟合得到：

```text
x+ = clamp((PWM - 1500) / 500, 0, 1)
x- = clamp((1500 - PWM) / 500, 0, 1)

F+   =  12.761 * x+^1.849 N       RMSE = 0.118 N
F-   =  -6.122 * x-^1.537 N       RMSE = 0.115 N
RPM+ =  20339 * x+^0.753 RPM      RMSE = 251 RPM
RPM- = -20790 * x-^0.689 RPM      RMSE = 294 RPM
```

关键实测值：

| PWM | 转速 | 推力 | 电流 |
|---:|---:|---:|---:|
| 1000 us | -20886.5 RPM | -6.020 N | 8.821 A |
| 1400 us | -7221.9 RPM | -0.617 N | 0.495 A |
| 1450 us | -4419.0 RPM | -0.182 N | 0.161 A |
| 1500 us | 0 RPM | -0.014 N（零点误差） | 0.003 A |
| 1600 us | +6165.8 RPM | +0.658 N | 0.356 A |
| 1650 us | +8527.8 RPM | +1.557 N | 0.759 A |
| 2000 us | +20645.0 RPM | +12.777 N | 9.031 A |

正反最大推力比约为 2.12:1。按实测角速度平方拟合：

- 正向推力常数：`2.626e-6 N/(rad/s)^2`
- 反向推力常数：`1.243e-6 N/(rad/s)^2`
- 正向力矩/推力比中位数：`0.02112 m`
- 反向力矩/推力比中位数：`0.04102 m`

## 3. 动态辨识边界

日志采样周期为 0.2 s，不能从数据中分辨 0.1～0.2 s 的换向瞬态。以下动态值采用实机观察形成工程模型，不属于台架日志直接辨识结果：

- Gazebo 一阶上升/下降时间常数：`0.05 s`
- PX4 尾电机过零等待：`0.15 s`

0.05 s 一阶时间常数对应约 0.15 s 完成 95% 阶跃变化；过零等待用于防止控制指令在零点附近频繁正反切换。二者职责不同：前者是执行器响应，后者是控制安全约束。

## 4. SITL 修改

仅修改 Motor 5，四个主电机保持原参数：

- Gazebo Motor 5 最大正向推力从 85.49 N 降至 12.777 N。
- 分配器对反向推力单独限制为 6.020 N。
- Gazebo 内部 `maxRotVelocity=1000`，所以使用 `motorConstant=1.2777084e-05`；它是为了匹配 Gazebo 内部速度尺度，不应和上面的实测物理转速常数混用。
- Motor 5 `timeConstantUp/Down` 均改为 0.05 s。
- Motor 5 `momentConstant` 使用正向拟合值 0.02112；当前 Gazebo 插件不支持分方向力矩常数，因此反转时的反扭矩仍会被低估。
- SITL `HNTR_MAX_TAIL_T=12.78`、`HNTR_TAIL_REV_T=0.15`。
- 当前 SDF 使用经 A/B 起飞验证可稳定的 `HNTR_CG_X=0.105`、`HNTR_CG_Z=-0.013` 和 `HNTR_TAU_P=8.0`。这两个 CG 数值是当前 SDF/控制器组合的几何假设，并非本次台架数据测量所得，也不能直接作为实机重心结论。

水平悬停所需重心补偿约为：

```text
重力俯仰力矩 = 4.5 * 9.81 * 0.105 = 4.635 N m
尾电机所需推力 = 4.635 / (0.105 + 0.664) = 6.027 N
预计 Gazebo 指令 = sqrt(6.027 / 12.777) = 0.687
```

## 6. 未解决与实机注意事项

- 5 Hz 台架数据不足以确定真实时间常数；若要辨识 0.1 s 量级瞬态，应以至少 100 Hz 同步记录 PWM、转速、电流和推力。
- 当前仿真没有复现双向电调的 PWM 死区，也没有复现正反方向不同的反扭矩；目标是先纠正推力量级和换向安全边界，而不是逐点复制真实电机。
- 台架数据明确显示中位点为 1500 us。若实机 Motor 5 的 `PWM_MAIN_DIS5/FAIL5` 仍为 1450 us，应在拆桨状态单独核对；本仿真分支没有修改实机 PWM 参数。
- 当前结果只证明 SITL 能起飞、悬停、降落并执行过零保护，不构成实机飞行验证。
