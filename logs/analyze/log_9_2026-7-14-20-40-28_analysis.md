# Hnuter 实机日志 9 姿态漂移与一级倾转振荡分析

日志：`logs/log_9_2026-7-14-20-40-28.ulg`

## 1. 飞行与估计器状态

- 日志时长 `377.1 s`，全程为 Position 模式，飞行中无 failsafe、无日志丢包。
- 两套 EKF 均健康，主实例没有切换；姿态四元数 reset counter 全程不变。
- 最大位置、高度、航向创新检验比分别约 `0.021 / 0.011 / 0.034`，远低于 1。
- 因此本次三轴姿态变化不是 EKF 跳变或状态估计发散造成的。

## 2. 姿态为什么在遥控输入回中后继续漂移

本次固件的 Hnuter RC 姿态逻辑把 AUX1、AUX2 和 yaw 输入积分成姿态目标。旧实现
在通道回中后保持“积分后的目标角”，并没有锁存回中瞬间的实际姿态。倾转机构和
机体存在滞后时，目标往往已经走在实际姿态前面，因此回中后飞机仍继续转动。

日志中检测到的回中后 2 秒姿态变化：

| 输入 | 中位数 | 95% | 最大值 |
|---|---:|---:|---:|
| AUX1 / roll | 1.83 deg | 9.92 deg | 16.83 deg |
| AUX2 / pitch | 2.92 deg | 13.96 deg | 22.34 deg |
| yaw | 4.65 deg | 14.50 deg | 17.17 deg |

这和观察到的“自发漂移”一致。代码已改为在输入由非零变为回中时锁存当前实测角度，
之后控制器保持该角度；进入 Position 模式时先锁存当前姿态，再按
`HNTR_RC_LVL_R` 渐进建立水平 roll/pitch 目标。

## 3. pitch 变大时一级倾转为什么摆动明显

一级倾转共同角与实际 pitch 的相关系数为 `0.997`。这是结构所需的正常补偿：机体
pitch 改变后，一级倾转必须反向调整推力方向，才能维持世界坐标系中的升力和水平力。

异常部分是一级倾转左右差动。以下信号都有明显的 `3.3-3.7 Hz` 主峰：

- roll rate；
- normalized roll torque setpoint；
- 一级倾转左右差动；
- 左右主电机推力差。

分配器使用 `alpha = atan2(Fx, Fz)`。pitch 增大时 `Fx` 增大，横滚力矩引起的左右
`Fz` 差会更强地转换成左右 `alpha` 差，所以原本的横滚闭环振荡会表现为一级倾转
明显摆动。20 秒窗口中，pitch 较大且横滚振荡最强的阶段，一级倾转差动标准差达到
约 `3.9-4.5 deg`，roll rate 标准差达到 `10.5-12.5 deg/s`。

本次参数 `HNTR_ATT_KR_R=18.2`、`HNTR_ATT_D_R=9.6`、`HNTR_TAU_R=56.3 Nm`
明显过于激进。`HNTR_TAU_R` 接近分配器可表示的整个归一化范围，失去了合理的保护
作用。物理舵机延迟没有进入控制模型，过高的 P/D 带宽会在约 3.5 Hz 处形成闭环振荡。

## 4. 姿态积分环缺陷

旧几何控制器只对 pitch 使用积分，并把误差积分硬限制为 `+-1.5`。本次
`HNTR_ATT_I_P=0.06` 时，积分最多只能输出 `0.06 * 1.5 = 0.09 Nm`，虽然
`HNTR_ATT_ILIM_P` 设置为 `0.8 Nm`，该上限实际上永远无法达到。这解释了之前只有
`HNTR_PITCH_BIAS` 明显有效，而调节 pitch I 收效很小的现象。

代码现已改为：

- roll/pitch/yaw 三轴均可配置姿态积分；
- `HNTR_ATT_ILIM_R/P/Y` 直接限制各轴积分力矩；
- landed/maybe_landed 时清零积分；
- 总力矩饱和且积分会继续推向饱和时停止积分。

新增参数为 `HNTR_ATT_I_R/Y` 和 `HNTR_ATT_ILIM_R/Y`；原 pitch 参数保持兼容。

## 5. 控制分配状态与剩余缺陷

- 四个主电机飞行段输出约 `0.50`，最大约 `0.70`，对应 PWM 最大 `1695-1700 us`；
  本次没有主电机上限饱和。
- 一级倾转共同角范围约 `-51.8~57.2 deg`，并未触及 `+-185 deg` 几何限位。
- active actuator 0-8 只有起落附近 5 个样本出现下限标志。状态中的 actuator 9-15
  固定上限标志来自未使用通道，不代表实际执行器饱和。
- Hnuter 分配器目前手工覆盖 actuator setpoint，并把 unallocated wrench 固定报告为 0。
  因而电机映射截断、舵机实际滞后和物理机构限速不会正确反馈给控制器。这是后续应
  修正的结构性缺陷。
- 分配器中的舵机指令限速仍硬编码为 `50 rad/s`，远快于实物机构，等同于没有动态
  模型。下一步应根据一级、二级机构实测最大角速度设置独立动态限制，并用限速后的
  实际方向重算可实现推力和 unallocated wrench，不能只对最终舵机指令简单限速。

## 6. 下一次实机测试参数

先关闭新增 AUX 姿态功能，单独确认水平 Position 悬停和 3.5 Hz 横滚振荡：

```sh
param set HNTR_RC_ATT_EN 0
param set HNTR_ATT_KR_R 10.0
param set HNTR_ATT_D_R 4.0
param set HNTR_TAU_R 15.0
param set HNTR_ACC_Z 8.0

param set HNTR_POS_P_XY 0.8
param set HNTR_VEL_P_XY 2.0
param set HNTR_VEL_I_XY 0.20
param set HNTR_VEL_D_XY 0.15

param set HNTR_ATT_I_R 0.0
param set HNTR_ATT_I_P 0.0
param set HNTR_ATT_I_Y 0.0
param set HNTR_TAU_Y 2.0
param save
```

确认一级倾转不再出现 3.3-3.7 Hz 连续摆动后，再启用姿态保持并逐轴测试：

```sh
param set HNTR_RC_ATT_EN 1
param set HNTR_RC_RATE_R 10
param set HNTR_RC_RATE_P 10
param set HNTR_RC_ANG_MAX 20
param save
```

最后才逐步加入积分。建议从 `HNTR_ATT_I_R=0.03`、`HNTR_ATT_ILIM_R=0.3 Nm`，
`HNTR_ATT_I_P=0.02`、`HNTR_ATT_ILIM_P=0.3 Nm`，`HNTR_ATT_I_Y=0.03`、
`HNTR_ATT_ILIM_Y=0.3 Nm` 开始。新代码下积分会真正达到设定的力矩范围，
因此已将实机 airframe 的 pitch I 默认值从旧的 `0.8` 改为 `0`，不应直接恢复过大值。
